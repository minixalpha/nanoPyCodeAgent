## Scored failures

- `model-extraction-relu-logits`: The agent ended with `response_truncated` after about 300 seconds. The official test failed because `/app/steal.py` was missing, so the required `/app/stolen_A1.npy` artifact was not produced. This is a scored failure, not a setup or verifier error.
- `schemelike-metacircular-eval`: The agent ended with `response_truncated` after about 1,162 seconds. The official evaluator passed 58 of 63 subcases and failed 5, producing reward 0. Two earlier model streams raised `RemoteProtocolError` and were retried successfully; their usage was unavailable. The verifier itself completed on its first attempt. The terminal outcome and incorrect subcases are separate observations, not proof that truncation caused every incorrect result.

## Interpretation and next work

This run establishes the actual released artifact's baseline before 0.10.0
feature changes. Response truncation is a concrete follow-up for 0.10.0:
inspect the failed cases and evaluate a bounded recovery policy in a separate
experiment, preserving this cohort's original scores.

The [September 30 run](deepseek-official-20260930.md) had 16 passed tasks,
2 scored failures, and 2 infrastructure exceptions. The task revisions are
unchanged, but the agent/harness revision, setup limit, cache state, and run date
differ. Earlier OpenRouter runs also used another model/provider configuration.
These records do not isolate the causal effect of an agent change. Pilot20 is
only this small task cohort, not a full 89-task Terminal-Bench score.
