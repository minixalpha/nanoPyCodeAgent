# 有界截断恢复：双任务实验

实验 agent 在冻结的 v0.9.0 pilot20 中失败的两题上取得 **2/2 通过**、**0 次计分
失败**和 **0 次未计分试验**。两次试验均未达到生成上限，因此均未触发自动恢复。
这些新运行的分数不能证明该策略带来收益。确定性测试覆盖恢复分支及其安全/预算
边界；线上有效性仍未得到证明。

## 假设与实现

此前，完整 API 响应若带有 `stop_reason="max_tokens"`，即使任务还有时间和回复
次数，headless 运行也会结束。现在允许每次 headless 运行继续一次，沿用原始
期限、回复次数和单次回复 token 上限。在请求历史中保留部分可见文本和提示，
丢弃该响应中所有未执行的工具调用和不完整 thinking。从已确认的工具结果和
当前文件继续，不重放此前工具操作。

继续事件记录为 `input.injected`，原因为 `truncation_recovery`，同时保留每次
模型尝试的停止原因、用量和费用。传输重试或成功的工具操作不会重置该额度。
再次截断、达到回复上限或原始期限均会结束运行。交互模式仍在截断后将控制权
交还用户。

## 固定输入

- Agent 提交：`e1be6ed1f81a17d73677b414d4d913adb81e9e25`。
- 模型：`deepseek/deepseek-flash`，端点 `https://api.deepseek.com/anthropic`。
- 100 次模型回复，每次回复最多生成 65,536 token。
- 模型提取工作预算 720 秒；Scheme 工作预算 2,220 秒。
- 设置时限 1,800 秒，与冻结的发布基线相同。
- 每题一次新运行，无整次试验重试。两个单任务标准 Harbor 作业同时运行，最多
  两次并行试验。
- 保留官方任务修订、镜像、包源和测试。全部 73 个记录的任务文件哈希不变，
  任务校验和与预检一致。仅 verifier 超时可重试，沿用原始单次时限，在同一
  agent 输出上最多尝试三次。

[预先声明的计划](../../configs/truncation-recovery-20261005/experiment.json)包含
任务修订、预算、源码/配置哈希和分析规则。实验 agent 的两次仅安装检查均通过。
两项 verifier 依赖配置均明确报告 `not_configured`；安装成功不代表 verifier
依赖已获认证。

预检和两次线上运行的 wheel 逐字节一致。两题的镜像和完整任务校验和均与发布
基线相同。两个官方 verifier 均在第一次尝试中完成；Scheme 通过全部 63 个子用例。

## 验证与解读

- 核心测试：锁定依赖下 351 项通过、4 项可选传输测试跳过；Anthropic SDK 1.5.0
  下 355 项通过。
- Harbor 工作流/ATIF 契约：91 项通过，包括工具调用截断后模型响应恢复的情形。
- 确定性测试覆盖：通过工具工作继续直至完成、跨传输重试的每次运行仅恢复一次
  上限、期限和回复限制不变、丢弃截断工具/thinking、不重复执行已确认的工具、
  交互行为不变，以及保留用量/费用总额。
- 线上轨迹校验和源码/任务完整性检查记录在结构化结果中。

[发布基线](v0.9.0-baseline-20261005.md)仍为 **18/20**。这两个新结果不替换其
失败，也不构成修订后的 pilot20 分数。它们使用新的模型生成和不同的并发任务
配对；不存在针对旧失败响应的确定性反事实。
