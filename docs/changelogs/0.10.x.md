# Changelog — 0.10.x

All notable changes in the **0.10.x** release series are documented here.

## [Unreleased]

### Added
- Add opt-in verified PyPI and original uv/Python caches for restricted Harbor runs, with temporary
  helpers limited to dependency preparation and official verification,
  confirmed removal before model work, and preserved partial setup output.
- Add a shared `restricted-v1` Harbor evaluation protocol for Nano, Pi, and
  DeepSeek Harness, with external network allowlists, isolation preflight,
  protected evidence, and integrity-adjusted scoring that retains violations in
  the denominator. Preserve native resource budgets and writable non-root
  verifier logs; require an explicit opt-out for registered historical
  open-network runs.
- Add retained-workspace Harbor verification, reviewed dependency preparation
  with independent deadlines, and opt-in collection-error recovery while
  preserving native verifier limits and prior evidence.
- Add pinned Pi agent baselines to the standard Harbor workflow, with offline
  model-registration checks, verified image caching, process supervision before
  grading, and explicit partial usage and cost accounting.
- Add official DeepSeek Harness `sdk-minimal` baselines to the standard Harbor
  workflow, with pinned offline SDK/runtime artifacts, verified PyPI wheel
  caching, reviewed dependency profiles, and bilingual audited comparison reports.

### Fixed
- Preserve long native JSON events in restricted Harbor output collection with
  UTF-8-aware chunked reads, retaining command deadlines and process cleanup.

### Changed
- Clarify headless task contracts, output verification, and permitted references.
  Allow task-supplied source, executables, and tests unless the task restricts
  them; restrict externally obtained task-specific answers and hidden tests.
- Allow headless tasks to recover once after a response reaches `max_tokens`,
  within the original time and reply budgets and without raising the token
  limit. Skip all tools from the truncated response and remove unfinished
  thinking from follow-up requests. Preserve per-attempt usage and costs, and
  record the recovery prompt in Journal and ATIF. A second truncation still
  stops the run; interactive mode continues to wait for user input.
