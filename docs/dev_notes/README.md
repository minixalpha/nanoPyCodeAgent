# Development Notes

Development notes for nanoPyCodeAgent, organized one file per `X.Y.x` release
series (e.g. `0.1.x.md`).

Notes are bilingual, split by language:

- [`zh-CN/`](zh-CN/) — **Chinese source** (source of truth)
- [`en/`](en/) — **English, generated from the Chinese source** (do not edit by hand)

These are free-form notes — insights, takeaways, and design decisions gathered
while developing each series, with no fixed structure. User-facing changes live
in [`../changelogs/`](../changelogs/).

The date in a `## X.Y.Z - YYYY.MM.DD` section heading is the **release date**
of that version (the same date as the git tag and the changelog entry). While
the version is unreleased, keep the literal `YYYY.MM.DD` placeholder — it is
filled in by the release process.

Current release series: **0.9.x** ([Chinese source](zh-CN/0.9.x.md),
[English version](en/0.9.x.md)). The **0.8.x** notes retain the development
record for v0.8.0 ([Chinese source](zh-CN/0.8.x.md),
[English version](en/0.8.x.md)).

Development toward **0.10.x** starts with the frozen v0.9.0 benchmark baseline
([Chinese source](zh-CN/0.10.x.md), [English version](en/0.10.x.md)).
