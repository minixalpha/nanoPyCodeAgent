## 0.10.0 - YYYY.MM.DD

### 开发前先固定 0.9.0 的 20 题 baseline

0.9.0 发布后，于 2026-10-05 重新完整运行原来的 Terminal-Bench 2.1 pilot20，
作为 0.10.0 开发前的起点。Agent 和 Harbor adapter 都固定到发布提交
`c0605369d277352ac0d5ec20d02017b7cb149314`；预检和四组正式运行的 wheel 均与 PyPI
0.9.0 发布包的 SHA256 一致。运行期间没有改动 agent 或 harness 源码。

使用 DeepSeek 官方 Anthropic 兼容端点、`deepseek-flash`、100 回合和每次请求
65,536 输出 token 上限。每题工作预算仍为原始 agent 时限减 180 秒；标准入口按
720、1,620、2,220、3,420 秒分成四组，合计 20 题，每题只运行一次，组内并发为 2。
依赖安装时限明确从历史默认 360 秒调到 1,800 秒，不占用题目的工作预算，原始
逐次 verifier 时限保持不变。

先做 install-only：20 题 agent 安装全部通过；QEMU 已注册的 verifier 依赖
profile 通过，其余 19 题明确记录为 `not_configured`。任务镜像、APT 源和官方
测试保持原样，缓存命中按原索引的文件名、大小和 SHA256 校验。

最终结果是 **18/20 通过、2 题评分失败、0 题未评分**。两道评分失败为
`model-extraction-relu-logits`（缺少要求的脚本和输出文件）与
`schemelike-metacircular-eval`（63 个子例通过 58 个）。两题的原生终态均为
`response_truncated`，但终态本身不能证明全部错误都由截断导致。所有原生
trajectory 均通过 ATIF 校验，保留所有试次，没有用重跑替换失败分数。

已知 token 费用估算小计为 **$1.974266**。Scheme 任务有两次已恢复的模型流
中断，其 usage 缺失，因此 token 总数和费用都不完整，不能把缺失部分当作零，也
不能把估算小计当成实际账单。
