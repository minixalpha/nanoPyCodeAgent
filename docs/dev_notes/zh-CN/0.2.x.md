## 0.2.0 - 2026.06.29

这个版本实现了一个最小功能的 chatbot，使用 [Message](https://platform.claude.com/docs/en/api/python/messages/create) 接口，完成与 LLM 的多轮对话。

LLM 的 endpoint、key、model 支持两种配置方式：

- **环境变量**：变量名参考 [Claude Code Environment variables](https://code.claude.com/docs/en/env-vars)，常用的三个是 `ANTHROPIC_API_KEY`、`ANTHROPIC_BASE_URL`、`ANTHROPIC_MODEL`。
- **配置文件**：路径为 `~/.nanoPyCodeAgent/settings.json`，在其 `env` 字段中配置，写法与 [Claude Code Settings](https://code.claude.com/docs/en/settings) 的 `env` 字段一致，示例：

  ```json
  {
    "env": {
      "ANTHROPIC_API_KEY": "",
      "ANTHROPIC_BASE_URL": "",
      "ANTHROPIC_MODEL": ""
    }
  }
  ```

两者可以混用，**环境变量优先级高于配置文件**：某个键在环境变量中已设置时，配置文件里的同名值会被忽略；配置文件只用于填补环境变量未设置的键。示例中的空串是占位符，空值（空串或纯空白）会被跳过。
