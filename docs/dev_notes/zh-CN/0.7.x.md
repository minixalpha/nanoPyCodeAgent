## 0.7.0 - 2026.08.16

这个版本开发 edit 工具，先对主流 code agent 的 edit 工具作了调研，见 [edit 工具调研](../../research/edit_tool.md)。开发 edit 工具最基本的初衷是，编辑一个文件的时候，只用传 diff 就可以了，不必把完整的文件来回传来传去，减少了信息的传输，也减少了上下文长度。当然，其实也可通过 bash 对文件进行部分编辑，但直觉上讲，不如专用工具稳定，也无法像专用工具一样，提供更多任务执行的上下文信息。

我测试了没有 edit 工具的情况，先写了个 quick_sort.py 文件，再要求添加注释的时候，0.6.x 版本的 nanoPyCodeAgent 就会调用 write 工具，对整个文件进行重写，验证了无 edit 工具时，会增加上下文。
